Testing this hypothesis in a clean, standalone Python environment—completely decoupled from `psc`—is the right engineering move. Before mapping anything into a compiler, you need an empirical inventory of what actually exists across a Python installation: what is available without a single `import` statement, what is baked into the C binary, what lives in the versioned standard library (both public facades and private `_` implementation modules), and what comes from external distributions.

To satisfy both goals—capturing 100% of Python's nuances now while ensuring the database remains universal for future languages—the architecture below uses a **Dual-Layer Schema Strategy**:

1. **A Language-Agnostic Core Schema** where Python's ambient scope, modules, classes, functions, parameters, and variables map to universal compiler concepts (`containers`, `symbols`, `callables`, `parameters`, `state_members`, `symbol_aliases`).
2. **A 1:1 Python Fidelity Extension (Facet Tables)** that attaches Python-specific mechanics (such as `builtins` vs. `site` injection, C-extension vs. frozen origin, `__all__` export status, descriptor kinds, and dunder protocols) without polluting the language-agnostic tables.

## 2. Capturing Public vs. Hidden Details & Re-Exports

A major pitfall when cataloging Python is assuming that the module where a user accesses a function is the module where that function is actually defined, or assuming that `_` prefixes mean only one thing. In Python, a complete catalog must classify **five distinct visibility and provenance rules**:

1. **Ambient Pure vs. Ambient `site`-Injected (Stratum 0)**:
* In a normal Python shell or script, `builtins` contains 158+ symbols. However, 6 of those (`quit`, `exit`, `copyright`, `credits`, `license`, `help`) are injected at startup by the `site` module. Running `python -S` omits them. Our catalog explicitly tags ` pure_builtin` vs. `site_injected_builtin`.


2. **Public Facade vs. Hidden C-Accelerator Origin (Stratum 1 & 2)**:
* When you call `json.encode_basestring_ascii`, its actual runtime `__module__` is `_json` (a compiled C extension). Similarly, `io.BufferedReader` originates in `_io`, `os.listdir` originates in `posix` (Linux/macOS) or `nt` (Windows), and `re.Pattern` originates in `_sre`.
* If you only catalog public modules, or if you don't separate **where a symbol is declared (`origin_container_id`)** from **where it is exposed (`exposed_in_container_id`)**, your transpiler loses the link between the public facade and the underlying implementation.


3. **The Four Visibility Tiers of Identifiers**:
* **`exported` (`__all__`)**: Explicitly listed in the module's `__all__` tuple/list.
* **`public_implicit`**: Does not start with `_`, and either `__all__` is absent or the symbol is accessible via standard attribute lookup.
* **`hidden_internal` (`_name`)**: Starts with a single underscore (e.g., `os._exit`, `sys._getframe`, `collections._Link`, or private submodules like `urllib._parse`). Crucial for low-level systems code and understanding stdlib internals.
* **`private_mangled` (`__name`)**: Inside a class body, starts with two underscores and does not end with two underscores; Python rewrites it at compile time to `_ClassName__name`.
* **`system_dunder` (`__name__`)**: Starts and ends with double underscores. Reserved by the language for operator overloading, lifecycle hooks, and module metadata.


4. **Defined-Here vs. Imported-Through Namespace Pollution**:
* In Python, if module `shutil.py` writes `import os, sys, stat` at the top of the file, `shutil.__dict__` now contains `shutil.os`, `shutil.sys`, and `shutil.stat`.
* A naive `dir(shutil)` harvester will record `os` as a submodule of `shutil`!
* To prevent graph corruption, every member in a module's namespace must be classified by **Provenance**:
* `defined_here`: `obj.__module__ == module.__name__` (or defined in the module's AST).
* `re_exported`: Imported from a private C-accelerator (`_io` $\to$ `io`) or explicitly listed in `__all__`.
* `imported_dependency`: An external module or foreign symbol imported purely as an implementation detail (recorded in `symbol_aliases` with `alias_kind = 'imported_reference'`, never duplicated as a primary definition).

## 3. Language-Agnostic Core Schema + Python Fidelity Facets

Rather than building a Python-only database and rewriting it later, we can structure the SQLite database right now into **two clean layers**:

* **Core Universal Tables (`1` to `8`)**: Completely language-agnostic. They model **Environments**, **Packages/Distributions**, **Containers** (ambient scopes, modules, namespaces, classes, interfaces), **Callables** (functions, methods, constructors, operators), **Parameters**, **State Members** (variables, constants, properties, fields), and **Cross-Container Aliases/Re-exports**.
* **Python Facet Tables (`9` to `10`)**: Attached via `1:1` foreign keys (`container_id`, `symbol_id`) to store Python-specific runtime metadata (C-extension vs. frozen, descriptor protocol flags, `inspect` signature fallbacks, `co_flags`). When you later add Rust, C#, or TypeScript, they share Tables `1–8` and simply add their own facet table if needed.

## 4. Clean-Room Standalone Harvester (`python_spectrum_harvester.py`)

This single-file script requires **zero external dependencies** and **zero `psc` code**. You can drop it into any clean directory or virtual environment and run it with any Python interpreter (`3.10` through `3.14+`).

### How It Safely Harvests Both Public & Hidden Details

1. **Stratum 0 (Ambient Scope)**:
* Catalogs all hard keywords (`keyword.kwlist`) and soft keywords (`keyword.softkwlist`).
* Launches a tiny `python -S -c` probe (clean interpreter without `site`) to identify exact pure builtins vs. `site`-injected builtins (`help`, `quit`, `exit`, `copyright`, `credits`, `license`).
* Introspects every function, class, exception (including all its methods, descriptors, and base classes), and constant in `builtins`.
* Catalogs implicit module-level dunders (`__name__`, `__doc__`, `__package__`, `__loader__`, `__spec__`, `__file__`, `__cached__`, `__builtins__`, `__annotations__`) inside the ambient container.


2. **Stratum 1 (Versioned Python Installation & Stdlib)**:
* Enumerates `sys.builtin_module_names` and `sys.stdlib_module_names`, plus discovers top-level private `_` modules in `sysconfig.get_path('stdlib')` and `platstdlib` (`lib-dynload`).
* Skips known side-effect/GUI modules (`antigravity`, `this`, `tkinter`, `idlelib`, `turtledemo`, `test`).
* Harvests both public (`json`, `os`, `sys`, `collections`) and hidden (`_io`, `_json`, `_sre`, `_collections`, `posix`/`nt`) modules, classifying every symbol's visibility (`exported`, `public_implicit`, `hidden_internal`, `private_mangled`, `system_dunder`) and provenance (`defined_here` vs. `re_exported` vs. `imported_dependency`).


3. **Stratum 2 (Installed Third-Party Packages)**:
* Uses `importlib.metadata.distributions()` to record installed packages and versions, and harvests any requested third-party packages (`--third-party numpy requests ...` or `--all-third-party`).

def classify_identifier_visibility(name: str, dunder_all: set[str] | None = None) -> tuple[str, int]:
    """Returns (visibility_tier, is_hidden_int)."""
    if name.startswith("__") and name.endswith("__") and len(name) > 4:
        return ("system_dunder", 0)
    if name.startswith("__") and not name.endswith("__"):
        return ("private_mangled", 1)
    if name.startswith("_"):
        return ("hidden_internal", 1)
    if dunder_all is not None:
        if name in dunder_all:
            return ("exported_all", 0)
        return ("public_implicit", 0)
    return ("public_implicit", 0)


def safe_repr(val: Any, max_len: int = 160) -> str | None:
    """Produces a deterministic, bounded string representation for constants/variables."""
    try:
        if isinstance(val, (int, float, bool, str, bytes, complex)) or val is None or val is Ellipsis or val is NotImplemented:
            r = repr(val)
            return r if len(r) <= max_len else r[: max_len - 3] + "..."
        return f"<{type(val).__name__}>"
    except Exception:
        return "<unrepresentable>"


def compute_file_sha256(path_str: str | None) -> str | None:
    if not path_str:
        return None
    p = Path(path_str)
    if not p.is_file():
        return None
    try:
        return hashlib.sha256(p.read_bytes()).hexdigest()
    except OSError:
        return None


def get_pure_builtins_without_site() -> set[str]:
    """Runs `python -S` in a clean subprocess to separate pure builtins from `site`-injected ones."""
    try:
        out = subprocess.check_output(
            [sys.executable, "-S", "-c", "import builtins, json; print(json.dumps(list(builtins.__dict__.keys())))"],
            text=True,
            timeout=5,
        )
        return set(json.loads(out.strip()))
    except Exception:
        return set(builtins.__dict__.keys())


def extract_callable_signature(obj: Any) -> tuple[str | None, str, str | None, list[dict[str, Any]]]:
    """
    Extracts (raw_signature, signature_source, return_type_expr, parameters_list)
    from Python functions, C builtins (`__text_signature__`), or docstring headers.
    """
    params_list: list[dict[str, Any]] = []
    try:
        sig = inspect.signature(obj)
        ret_expr = None
        if sig.return_annotation is not inspect.Signature.empty:
            ret_expr = (
                sig.return_annotation
                if isinstance(sig.return_annotation, str)
                else getattr(sig.return_annotation, "__name__", str(sig.return_annotation))
            )

        for idx, (_, param) in enumerate(sig.parameters.items()):
            kind_map = {
                inspect.Parameter.POSITIONAL_ONLY: "positional_only",
                inspect.Parameter.POSITIONAL_OR_KEYWORD: "positional_or_keyword",
                inspect.Parameter.VAR_POSITIONAL: "var_positional",
                inspect.Parameter.KEYWORD_ONLY: "keyword_only",
                inspect.Parameter.VAR_KEYWORD: "var_keyword",
            }
            ann_str = None
            if param.annotation is not inspect.Parameter.empty:
                ann_str = (
                    param.annotation
                    if isinstance(param.annotation, str)
                    else getattr(param.annotation, "__name__", str(param.annotation))
                )
            def_str = None
            is_opt = 0
            if param.default is not inspect.Parameter.empty:
                def_str = safe_repr(param.default, 80)
                is_opt = 1
            elif param.kind in (inspect.Parameter.VAR_POSITIONAL, inspect.Parameter.VAR_KEYWORD):
                is_opt = 1

            params_list.append({
                "ordinal": idx,
                "name": param.name,
                "pass_kind": kind_map.get(param.kind, "positional_or_keyword"),
                "type_expr": ann_str,
                "default_expr": def_str,
                "is_optional": is_opt,
            })

        source = "text_signature" if getattr(obj, "__text_signature__", None) else "inspect_signature"
        return (str(sig), source, ret_expr, params_list)
    except (ValueError, TypeError):
        # Fallback for C builtins whose __text_signature__ is None but whose docstring starts with `func(...)`
        doc = getattr(obj, "__doc__", None)
        if isinstance(doc, str) and doc.strip():
            first_line = doc.strip().splitlines()[0].strip()
            if "(" in first_line and ")" in first_line:
                return (first_line, "docstring_first_line", None, [])
        return (None, "unknown", None, [])

class PythonSpectrumCataloger:
    def __init__(self, conn: sqlite3.Connection) -> None:
        self.conn = conn
        self.env_id: int = -1
        self.pure_builtin_names: set[str] = get_pure_builtins_without_site()

    def init_db(self, reset: bool = False) -> None:
        if reset:
            for tbl in (
                "py_symbol_facets", "py_container_facets", "symbol_aliases",
                "state_members", "parameters", "callables", "symbols",
                "containers", "distributions", "environments",
            ):

        self.conn.executescript(SCHEMA_SQL)
        self.conn.commit()

    def register_environment(self) -> int:
        vi = sys.version_info
        plat = f"{platform.system()}-{platform.machine()}"
        cur = self.conn.execute(
            """
            INSERT INTO environments (
                language, runtime_name, language_version,
                version_major, version_minor, version_micro,
                platform_triplet, executable_path
            )
            VALUES ('python', ?, ?, ?, ?, ?, ?, ?)
            ON CONFLICT(language, runtime_name, language_version, platform_triplet, executable_path)
            DO UPDATE SET captured_at = CURRENT_TIMESTAMP
            RETURNING env_id
            """,
            (
                platform.python_implementation(),
                platform.python_version(),
                vi.major,
                vi.minor,
                vi.micro,
                plat,
                sys.executable,
            ),
        )
        self.env_id = int(cur.fetchone()[0])
        self.conn.commit()
        return self.env_id

    def register_distribution(self, stratum: int, dist_name: str, dist_version: str, summary: str | None = None) -> int:
        cur = self.conn.execute(
            """
            INSERT INTO distributions (env_id, stratum, dist_name, dist_version, summary)
            VALUES (?, ?, ?, ?, ?)
            ON CONFLICT(env_id, stratum, dist_name, dist_version)
            DO UPDATE SET summary = COALESCE(excluded.summary, distributions.summary)
            RETURNING dist_id
            """,
            (self.env_id, stratum, dist_name, dist_version, summary),
        )
        return int(cur.fetchone()[0])

    def register_container(
        self,
        *,
        dist_id: int,
        parent_id: int | None,
        container_kind: str,
        qualified_name: str,
        short_name: str,
        requires_import: int,
        visibility: str,
        is_hidden: int,
        physical_path: str | None = None,
        docstring: str | None = None,

        dunder_all: list[str] | None = None,
        has_lazy_getattr: bool = False,
        base_classes: list[str] | None = None,
        mro_list: list[str] | None = None,
        metaclass_name: str | None = None,

        sha = compute_file_sha256(physical_path)
        cur = self.conn.execute(
            """
            INSERT INTO containers (
                dist_id, parent_container_id, container_kind, qualified_name,
                short_name, requires_import, visibility, is_hidden,
                physical_path, sha256_hash, docstring
            )
            VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
            ON CONFLICT(dist_id, qualified_name) DO UPDATE SET
                physical_path = COALESCE(excluded.physical_path, containers.physical_path),
                docstring = COALESCE(excluded.docstring, containers.docstring)
            RETURNING container_id
            """,
            (
                dist_id, parent_id, container_kind, qualified_name,
                short_name, requires_import, visibility, is_hidden,
                physical_path, sha, docstring,
            ),
        )
        cid = int(cur.fetchone()[0])

        self.conn.execute(
            """
            INSERT INTO py_container_facets (
                container_id, module_origin_kind, has_dunder_all, dunder_all_json,
                has_lazy_getattr, base_classes_json, mro_json, metaclass_name
            )

            (
                cid,

                1 if dunder_all is not None else 0,

                1 if has_lazy_getattr else 0,
                json.dumps(base_classes) if base_classes is not None else None,
                json.dumps(mro_list) if mro_list is not None else None,
                metaclass_name,
            ),
        )
        return cid

    def discover_stdlib_modules(self, include_submodules: bool = False) -> list[str]:
        """Discovers built-in C modules, sys.stdlib_module_names, and top-level `_` internal modules."""
        names: set[str] = set(sys.builtin_module_names)
        if hasattr(sys, "stdlib_module_names"):
            names.update(sys.stdlib_module_names)

        # Also scan stdlib and lib-dynload directories for private `_` C-accelerators or internal modules
        for path_key in ("stdlib", "platstdlib"):
            p_str = sysconfig.get_path(path_key)
            if p_str and Path(p_str).is_dir():
                for mod_info in pkgutil.iter_modules([p_str]):
                    names.add(mod_info.name)

        filtered = sorted(
            n for n in names
            if n not in SIDE_EFFECT_STDLIB_MODULES and not n.startswith("test.")
        )

        if not include_submodules:
            return filtered

        # Optionally expand submodules of top-level packages safely via pkgutil
        expanded: list[str] = []
        for mod_name in filtered:
            expanded.append(mod_name)
            try:
                spec = importlib.util.find_spec(mod_name)
                if spec and spec.submodule_search_locations:
                    for sub in pkgutil.walk_packages(spec.submodule_search_locations, prefix=f"{mod_name}."):
                        if not any(part in SIDE_EFFECT_STDLIB_MODULES for part in sub.name.split(".")):
                            expanded.append(sub.name)
            except Exception:
                continue
        return sorted(set(expanded))

    def harvest_stratum_1_stdlib(self, module_filter: set[str] | None = None, include_submodules: bool = False) -> None:
        py_ver = platform.python_version()
        dist_id = self.register_distribution(
            stratum=1,
            dist_name="python-stdlib",
            dist_version=py_ver,
            summary=f"Standard library and compiled-in modules shipped with {platform.python_implementation()} {py_ver}.",
        )

        candidates = self.discover_stdlib_modules(include_submodules=include_submodules)
        if module_filter:
            candidates = [
                m for m in candidates
                if m in module_filter or m.split(".")[0] in module_filter
            ]

        for mod_name in candidates:
            self.harvest_module_by_name(dist_id=dist_id, mod_name=mod_name)
        self.conn.commit()

    # STRATUM 2: ENVIRONMENT THIRD-PARTY PACKAGES
    # ========================================================================

    def harvest_stratum_2_third_party(self, target_packages: set[str] | None = None) -> None:
        pkg_to_dists = importlib.metadata.packages_distributions()
        visited_dists: set[tuple[str, str]] = set()

        for dist in importlib.metadata.distributions():
            dist_name = dist.metadata["Name"] or "unknown"
            dist_ver = dist.version or "0.0.0"
            if (dist_name, dist_ver) in visited_dists:
                continue
            visited_dists.add((dist_name, dist_ver))

            summary = dist.metadata.get("Summary")
            dist_id = self.register_distribution(
                stratum=2,
                dist_name=dist_name,
                dist_version=dist_ver,
                summary=summary,
            )

            if target_packages is not None:
                # Harvest only if requested by distribution name or importable package name
                top_pkgs = [
                    pkg for pkg, d_names in pkg_to_dists.items()
                    if dist_name in d_names
                ]
                if dist_name not in target_packages and not any(p in target_packages for p in top_pkgs):
                    continue
                for pkg in sorted(set(top_pkgs)):
                    if pkg in target_packages or dist_name in target_packages:
                        self.harvest_module_by_name(dist_id=dist_id, mod_name=pkg)
        self.conn.commit()

    # ========================================================================
    # CORE MODULE, CLASS, CALLABLE & VARIABLE INTROSPECTION
    # ========================================================================

    def _classify_module_origin(self, mod_name: str, mod: types.ModuleType) -> tuple[str, str | None]:
        if mod_name in sys.builtin_module_names:
            return ("builtin_c", None)
        spec = getattr(mod, "__spec__", None)
        origin = getattr(spec, "origin", None) if spec else getattr(mod, "__file__", None)
        if origin == "frozen" or (spec and getattr(spec, "loader", None) and "Frozen" in type(spec.loader).__name__):
            return ("frozen", None)
        if origin == "built-in":
            return ("builtin_c", None)
        if spec and spec.submodule_search_locations and origin is None:
            return ("namespace_pkg", None)
        if isinstance(origin, str):
            for ext in importlib.machinery.EXTENSION_SUFFIXES:
                if origin.endswith(ext):
                    return ("c_extension", origin)
            return ("pure_python", origin)
        return ("unknown", None)

    def harvest_module_by_name(self, dist_id: int, mod_name: str) -> int | None:
        if mod_name in SIDE_EFFECT_STDLIB_MODULES:
            return None
        try:
            mod = importlib.import_module(mod_name)
        except Exception:
            return None

        origin_kind, phys_path = self._classify_module_origin(mod_name, mod)
        is_pkg = hasattr(mod, "__path__")
        container_kind = "package" if is_pkg else "module"
        short_name = mod_name.rsplit(".", 1)[-1]
        vis, is_hid = classify_identifier_visibility(short_name)

        raw_all = getattr(mod, "__all__", None)
        dunder_all_list = [str(x) for x in raw_all] if isinstance(raw_all, (list, tuple, set, frozenset)) else None
        dunder_all_set = set(dunder_all_list) if dunder_all_list is not None else None
        has_lazy_getattr = "__getattr__" in mod.__dict__

        parent_cid: int | None = None
        if "." in mod_name:
            parent_name = mod_name.rsplit(".", 1)[0]
            row = self.conn.execute(
                "SELECT container_id FROM containers WHERE dist_id = ? AND qualified_name = ? LIMIT 1",
                (dist_id, parent_name),
            ).fetchone()
            if row:
                parent_cid = int(row[0])

        mod_cid = self.register_container(
            dist_id=dist_id,
            parent_id=parent_cid,
            container_kind=container_kind,
            qualified_name=mod_name,
            short_name=short_name,
            requires_import=1,
            visibility=vis,
            is_hidden=is_hid,
            physical_path=phys_path,
            docstring=inspect.getdoc(mod),
            module_origin_kind=origin_kind,
            dunder_all=dunder_all_list,
            has_lazy_getattr=has_lazy_getattr,
        )

        # Inspect every attribute in `mod.__dict__` (both public and hidden `_`)
        for attr_name, obj in sorted(mod.__dict__.items()):
            if attr_name in IMPLICIT_MODULE_DUNDERS or attr_name in ("__all__", "__path__"):
                continue

            # 1. If `obj` is an imported module object (e.g. `import sys` inside `os.py`), record as alias, not child definition!
            if isinstance(obj, types.ModuleType):
                target_mod_name = getattr(obj, "__name__", attr_name)
                in_all = 1 if (dunder_all_set and attr_name in dunder_all_set) else 0
                self.conn.execute(
                    """
                    INSERT INTO symbol_aliases (
                        source_container_id, exposed_name, target_module_name,
                        target_symbol_name, alias_kind, is_in_dunder_all
                    )
                    VALUES (?, ?, ?, '<module>', 'imported_module_ref', ?)
                    ON CONFLICT(source_container_id, exposed_name) DO NOTHING
                    """,
                    (mod_cid, attr_name, target_mod_name, in_all),
                )
                continue

            # 2. Check provenance: Was this callable/class defined in `mod_name`, re-exported from a `_` C module, or imported?
            obj_mod = getattr(obj, "__module__", None)
            if isinstance(obj_mod, str) and obj_mod != mod_name:
                in_all = dunder_all_set is not None and attr_name in dunder_all_set
                # Check if `obj_mod` is a private backing module for `mod_name` (e.g., `_io` for `io`, `posix` for `os`, `_json` for `json`)
                is_backing_c_mod = (
                    obj_mod.startswith(f"_{mod_name.split('.')[0]}")
                    or obj_mod.startswith(f"{mod_name}._")
                    or (mod_name == "os" and obj_mod in ("posix", "nt", "genericpath", "posixpath", "ntpath"))
                )
                alias_kind = (
                    "c_accelerator_reexport"
                    if is_backing_c_mod
                    else ("explicit_all_reexport" if in_all else "imported_symbol_ref")
                )
                self.conn.execute(
                    """
                    INSERT INTO symbol_aliases (
                        source_container_id, exposed_name, target_module_name,
                        target_symbol_name, alias_kind, is_in_dunder_all
                    )
                    VALUES (?, ?, ?, ?, ?, ?)
                    ON CONFLICT(source_container_id, exposed_name) DO NOTHING
                    """,
                    (
                        mod_cid,
                        attr_name,
                        obj_mod,
                        getattr(obj, "__name__", attr_name),
                        alias_kind,
                        1 if in_all else 0,
                    ),
                )
                # If it is an accidental imported dependency (not in __all__ and not a backing C module), do not duplicate into `symbols`
                if not in_all and not is_backing_c_mod:
                    continue
                provenance = "re_exported"
            else:
                provenance = "defined_here"

            self._harvest_Runtime_member(
                dist_id=dist_id,
                parent_cid=mod_cid,
                parent_qname=mod_name,
                module_name=mod_name,
                name=attr_name,
                obj=obj,
                dunder_all=dunder_all_set,
                requires_import=1,
                override_provenance=provenance,
            )

        return mod_cid

    def _harvest_Runtime_member(
        self,
        *,
        dist_id: int,
        parent_cid: int,
        parent_qname: str,
        module_name: str,
        name: str,
        obj: Any,
        dunder_all: set[str] | None,
        requires_import: int,
        override_provenance: str,
        is_inside_class: bool = False,
    ) -> None:
        vis, is_hid = classify_identifier_visibility(name, dunder_all)
        qname = f"{parent_qname}.{name}"
        py_type_name = type(obj).__name__
        dunder_cat = DUNDER_CATEGORIES.get(name)

        # Case A: Class / Type / Exception
        if inspect.isclass(obj):
            is_exc = issubclass(obj, BaseException)
            sym_kind = "exception" if is_exc else "class"
            container_kind = "exception_class" if is_exc else "class"

            bases = [f"{b.__module__}.{b.__qualname__}" for b in getattr(obj, "__bases__", ())]
            mro = [f"{c.__module__}.{c.__qualname__}" for c in getattr(obj, "__mro__", ())]

            # Register the class as a symbol in its parent container
            cur = self.conn.execute(
                """
                INSERT INTO symbols (
                    container_id, origin_container_id, name, qualified_name,
                    symbol_kind, visibility, provenance, is_hidden, docstring
                )
                VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)
                ON CONFLICT(container_id, name) DO NOTHING
                RETURNING symbol_id
                """,
                (parent_cid, parent_cid, name, qname, sym_kind, vis, override_provenance, is_hid, inspect.getdoc(obj)),
            )
            row = cur.fetchone()
            if row:
                sid = int(row[0])
                self.conn.execute(
                    """
                    INSERT INTO py_symbol_facets (symbol_id, py_runtime_type, is_c_implemented, dunder_category)
                    VALUES (?, ?, ?, ?)
                    """,
                    (sid, py_type_name, 0 if hasattr(obj, "__dict__") and "__module__" in obj.__dict__ else 1, dunder_cat),
                )
                # Also record the class constructor signature if extractable
                raw_sig, sig_src, ret_expr, params = extract_callable_signature(obj)
                self._insert_callable_and_params(
                    sid,
                    is_async=0,
                    is_generator=0,
                    is_static=0,
                    is_class_bound=1,
                    return_type_expr=name,
                    raw_signature=raw_sig,
                    signature_source=sig_src,
                    params=params,
                )

            # Avoid infinite recursion on nested self-referential classes
            if is_inside_class:
                return

            # Register the class as a Container to catalog its methods, descriptors, and class attributes
            cls_cid = self.register_container(
                dist_id=dist_id,
                parent_id=parent_cid,
                container_kind=container_kind,
                qualified_name=qname,
                short_name=name,
                requires_import=requires_import,
                visibility=vis,
                is_hidden=is_hid,
                docstring=inspect.getdoc(obj),
                module_origin_kind="class_body",
                base_classes=bases,
                mro_list=mro,
                metaclass_name=type(obj).__name__,
            )

            for m_name, m_obj in sorted(obj.__dict__.items()):
                if m_name in ("__dict__", "__weakref__", "__doc__", "__module__"):
                    continue
                self._harvest_Runtime_member(
                    dist_id=dist_id,
                    parent_cid=cls_cid,
                    parent_qname=qname,
                    module_name=module_name,
                    name=m_name,
                    obj=m_obj,
                    dunder_all=None,
                    requires_import=requires_import,
                    override_provenance="defined_here",
                    is_inside_class=True,
                )
            return

        # Case B: Descriptors & Properties inside classes (`property`, `classmethod`, `staticmethod`, `getset_descriptor`, `member_descriptor`)
        if isinstance(obj, property) or py_type_name in ("getset_descriptor", "member_descriptor", "DynamicClassAttribute"):
            acc_mode = "read_only"
            if isinstance(obj, property) and obj.fset is not None:
                acc_mode = "read_write_delete" if obj.fdel is not None else "read_write"
            elif py_type_name in ("getset_descriptor", "member_descriptor"):
                acc_mode = "read_write"

            cur = self.conn.execute(
                """
                INSERT INTO symbols (
                    container_id, origin_container_id, name, qualified_name,
                    symbol_kind, visibility, provenance, is_hidden, docstring
                )
                VALUES (?, ?, ?, ?, 'property', ?, ?, ?, ?)
                ON CONFLICT(container_id, name) DO NOTHING
                RETURNING symbol_id
                """,
                (parent_cid, parent_cid, name, qname, vis, override_provenance, is_hid, inspect.getdoc(obj)),
            )
            row = cur.fetchone()
            if row:
                sid = int(row[0])
                self.conn.execute(
                    """
                    INSERT INTO state_members (
                        symbol_id, declared_type_expr, runtime_type_name,
                        is_constant, is_mutable, literal_value_repr, access_mode
                    )
                    VALUES (?, NULL, ?, 0, 1, NULL, ?)
                    """,
                    (sid, py_type_name, acc_mode),
                )
                self.conn.execute(
                    """
                    INSERT INTO py_symbol_facets (symbol_id, py_runtime_type, descriptor_kind, is_c_implemented, dunder_category)
                    VALUES (?, ?, ?, ?, ?)
                    """,
                    (sid, py_type_name, py_type_name, 0 if isinstance(obj, property) else 1, dunder_cat),
                )
            return

        # Unwrap staticmethod / classmethod descriptors before inspecting the underlying function
        is_static = 0 if is_inside_class else 1
        is_class_bound = 0
        descriptor_kind: str | None = None
        underlying_obj = obj
        if isinstance(obj, staticmethod):
            is_static = 1
            descriptor_kind = "staticmethod"
            underlying_obj = obj.__func__
        elif isinstance(obj, classmethod):
            is_static = 0
            is_class_bound = 1
            descriptor_kind = "classmethod"
            underlying_obj = obj.__func__
        elif py_type_name == "classmethod_descriptor":
            is_class_bound = 1
            descriptor_kind = "classmethod_descriptor"

        # Case C: Functions, Methods, Built-in C Functions, Method Descriptors, Slot Wrappers
        if callable(underlying_obj) or py_type_name in (
            "method_descriptor", "wrapper_descriptor", "builtin_function_or_method", "classmethod_descriptor"
        ):
            sym_kind = "constructor" if name in ("__init__", "__new__") else ("method" if is_inside_class else "function")
            is_async = 1 if inspect.iscoroutinefunction(underlying_obj) or inspect.isasyncgenfunction(underlying_obj) else 0
            is_gen = 1 if inspect.isgeneratorfunction(underlying_obj) or inspect.isasyncgenfunction(underlying_obj) else 0
            code_obj = getattr(underlying_obj, "__code__", None)
            co_flags = getattr(code_obj, "co_flags", None)
            is_c_impl = 1 if code_obj is None else 0

            cur = self.conn.execute(
                """
                INSERT INTO symbols (
                    container_id, origin_container_id, name, qualified_name,
                    symbol_kind, visibility, provenance, is_hidden, docstring
                )
                VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)
                ON CONFLICT(container_id, name) DO NOTHING
                RETURNING symbol_id
                """,
                (parent_cid, parent_cid, name, qname, sym_kind, vis, override_provenance, is_hid, inspect.getdoc(underlying_obj)),
            )
            row = cur.fetchone()
            if row:
                sid = int(row[0])
                raw_sig, sig_src, ret_expr, params = extract_callable_signature(underlying_obj)
                self._insert_callable_and_params(
                    sid,
                    is_async=is_async,
                    is_generator=is_gen,
                    is_static=is_static,
                    is_class_bound=is_class_bound,
                    return_type_expr=ret_expr,
                    raw_signature=raw_sig,
                    signature_source=sig_src,
                    params=params,
                )
                self.conn.execute(
                    """
                    INSERT INTO py_symbol_facets (
                        symbol_id, py_runtime_type, descriptor_kind,
                        is_c_implemented, co_flags, dunder_category
                    )
                    VALUES (?, ?, ?, ?, ?, ?)
                    """,
                    (sid, py_type_name, descriptor_kind or py_type_name, is_c_impl, co_flags, dunder_cat),
                )
            return

        # Case D: Constants, Sentinels, and Module/Class State Variables
        is_const = 1 if (name.isupper() or name in ("True", "False", "None", "Ellipsis", "NotImplemented", "__debug__")) else 0
        is_mut = 0 if isinstance(obj, (int, float, str, bytes, tuple, frozenset, bool)) or obj is None else 1
        sym_kind = "constant" if is_const else "variable"

        cur = self.conn.execute(
            """
            INSERT INTO symbols (
                container_id, origin_container_id, name, qualified_name,
                symbol_kind, visibility, provenance, is_hidden, docstring
            )
            VALUES (?, ?, ?, ?, ?, ?, ?, ?, NULL)
            ON CONFLICT(container_id, name) DO NOTHING
            RETURNING symbol_id
            """,
            (parent_cid, parent_cid, name, qname, sym_kind, vis, override_provenance, is_hid),
        )
        row = cur.fetchone()
        if row:
            sid = int(row[0])
            self.conn.execute(
                """
                INSERT INTO state_members (
                    symbol_id, declared_type_expr, runtime_type_name,
                    is_constant, is_mutable, literal_value_repr, access_mode
                )
                VALUES (?, NULL, ?, ?, ?, ?, ?)
                """,
                (
                    sid,
                    py_type_name,
                    is_const,
                    is_mut,
                    safe_repr(obj),
                    "read_only" if is_const else "read_write",
                ),
            )
            self.conn.execute(
                """
                INSERT INTO py_symbol_facets (symbol_id, py_runtime_type, is_c_implemented, dunder_category)
                VALUES (?, ?, 1, ?)
                """,
                (sid, py_type_name, dunder_cat),
            )

    def _insert_callable_and_params(
        self,
        symbol_id: int,
        *,
        is_async: int,
        is_generator: int,
        is_static: int,
        is_class_bound: int,
        return_type_expr: str | None,
        raw_signature: str | None,
        signature_source: str,
        params: list[dict[str, Any]],
    ) -> None:
        self.conn.execute(
            """
            INSERT INTO callables (
                symbol_id, is_async, is_generator, is_static, is_class_bound,
                return_type_expr, raw_signature, signature_source
            )
            VALUES (?, ?, ?, ?, ?, ?, ?, ?)
            ON CONFLICT(symbol_id) DO NOTHING
            """,
            (symbol_id, is_async, is_generator, is_static, is_class_bound, return_type_expr, raw_signature, signature_source),
        )
        for p in params:
            self.conn.execute(
                """
                INSERT INTO parameters (
                    callable_symbol_id, ordinal, name, pass_kind,
                    type_expr, default_expr, is_optional
                )
                VALUES (?, ?, ?, ?, ?, ?, ?)
                ON CONFLICT(callable_symbol_id, ordinal) DO NOTHING
                """,
                (
                    symbol_id,
                    p["ordinal"],
                    p["name"],
                    p["pass_kind"],
                    p["type_expr"],
                    p["default_expr"],
                    p["is_optional"],
                ),
            )

def print_spectrum_report(conn: sqlite3.Connection, db_path: Path) -> None:
    print(f"\n======================================================================")
    print(f" PYTHON SPECTRUM CATALOG SUMMARY ({db_path})")
    print(f"======================================================================")

    env = conn.execute("SELECT * FROM environments LIMIT 1").fetchone()
    if env:
        print(f" Runtime   : {env[2]} {env[3]} on {env[7]} ({env[8]})")

    print("\n--- 1. Containers by Stratum & Origin Kind ---")
    rows = conn.execute(
        """
        SELECT d.stratum, d.dist_name, c.container_kind, f.module_origin_kind,
               SUM(CASE WHEN c.is_hidden = 0 THEN 1 ELSE 0 END) AS public_cnt,
               SUM(CASE WHEN c.is_hidden = 1 THEN 1 ELSE 0 END) AS hidden_cnt
        FROM containers c
        JOIN distributions d ON c.dist_id = d.dist_id
        LEFT JOIN py_container_facets f ON c.container_id = f.container_id
        WHERE c.container_kind IN ('ambient_scope', 'module', 'package')
        GROUP BY d.stratum, d.dist_name, c.container_kind, f.module_origin_kind
        ORDER BY d.stratum, c.container_kind
        """
    ).fetchall()
    for stratum, dist_name, c_kind, orig_kind, pub_c, hid_c in rows:
        print(f"  [Stratum {stratum}: {dist_name:<15}] {c_kind:<14} ({str(orig_kind):<12}) -> Public: {pub_c:>4}, Hidden (_): {hid_c:>4}")

    print("\n--- 2. Symbols by Stratum, Kind & Visibility ---")
    sym_rows = conn.execute(
        """
        SELECT d.stratum, s.symbol_kind, s.visibility, s.provenance, COUNT(*)
        FROM symbols s
        JOIN containers c ON s.container_id = c.container_id
        JOIN distributions d ON c.dist_id = d.dist_id
        GROUP BY d.stratum, s.symbol_kind, s.visibility, s.provenance
        ORDER BY d.stratum, COUNT(*) DESC
        """
    ).fetchall()
    for stratum, s_kind, vis, prov, cnt in sym_rows[:25]:
        print(f"  [Stratum {stratum}] {s_kind:<14} | vis={vis:<17} | prov={prov:<15} : {cnt:>6,}")

    print("\n--- 3. Cross-Module Re-Exports & C-Accelerator Aliases (Sample) ---")
    alias_rows = conn.execute(
        """
        SELECT c.qualified_name, a.exposed_name, a.target_module_name, a.target_symbol_name, a.alias_kind
        FROM symbol_aliases a
        JOIN containers c ON a.source_container_id = c.container_id
        WHERE a.alias_kind IN ('c_accelerator_reexport', 'explicit_all_reexport')
        LIMIT 12
        """
    ).fetchall()
    for src_mod, exp_name, tgt_mod, tgt_sym, akind in alias_rows:
        print(f"  {src_mod}.{exp_name:<22} -> {tgt_mod}.{tgt_sym:<22} ({akind})")


def main(argv: Sequence[str] | None = None) -> int:
